# Module 4: React Profile Card Application

This project is a student directory I created using React and TypeScript for MCON 505.

The website displays five student cards with each student's name, major, and graduation year.

I used JSX, functional components, and typed props to build the application.

## Components
- Header: Displays the title.
- StudentCard: Displays each student's information.
- Footer: Displays the footer message.

## How to Run
1. Open the project folder.
2. Run `npm install` in the terminal.
3. Run `npm run dev`.
4. Open the local URL in your browser.
